# Copywriting landingu ebooka

Kontekst pochodzi z dostarczonego przez użytkownika pliku
`10000000 Sales Copy Advice.md`, z repo `CRM-delivery-framework/frameworks/writing`.
Poniżej znajduje się adaptacja jego zasad do tego projektu. Nie trzeba mieć
dostępu do zewnętrznego pliku, aby zastosować skill.

Czytelniczka jest główną osobą w opowieści. Pisz o jej potrzebie, decyzji
i użytecznym wyniku. Produkt i doświadczenie autorki uzasadniają rozwiązanie.
Perswazja ma pokazywać prawdę o wartości produktu. Dopasuj język do odbiorczyni
i tematu konkretnego ebooka, bez sztucznego alarmu, presji i deklaracji bez źródła.

## Siedem "sales copy phrases"

To mechanizmy przekazu. Nie trzeba tłumaczyć ich dosłownie ani umieszczać
angielskich zdań na polskiej stronie. Przykłady dotyczą pierwszego ebooka;
nie są gotowymi nagłówkami dla każdej kolejnej oferty.

### 1. "This small action will lead to a giant outcome."

Połącz mały pierwszy krok z istotnym, wiarygodnym rezultatem.
W ebooku edukacyjnym pokaż np. jak jedna karta porównania pomaga uporządkować
rozmowę o suplementacji. Nie obiecuj wielkiego efektu zdrowotnego po samej
lekturze. Jeśli używasz tylko niewielkiej korzyści, oznacz zastosowanie jako częściowe.

### 2. "This massive problem can be fixed with this simple solution."

Pokaż prosty sposób poradzenia sobie z konkretną częścią problemu.
Przykład: zamiast porównywać przypadkowe listy suplementów, czytelniczka
porządkuje pytania o cel, dowody i własną sytuację. Wyjaśnij mechanizm materiału.
Nie sugeruj, że ebook usuwa PCOS lub zastępuje indywidualne leczenie.

### 3. "The outcome you want isn't far away."

Przybliż pierwszy użyteczny wynik, np. przygotowaną listę pytań na konsultację
po pracy z konkretnym arkuszem. Nie wymyślaj czasu lektury, natychmiastowej
wysyłki ani terminu poprawy zdrowia. Bliskość wyniku ma wynikać z materiału
i rzeczywistego sposobu dostarczenia ebooka.

### 4. "It's not your fault."

Nazwij trudność z empatią. Sprzeczne porady mogą utrudniać decyzję nawet osobie,
która już szuka informacji. Nie zawstydzaj czytelniczki za wcześniejsze wybory.
Nie wymyślaj winnego ani historii zaniedbania. Sam opis chaosu bez empatii
nie wystarcza do uznania tej zasady za w pełni zastosowaną.

### 5. "You've already done the hardest part."

Uznaj wysiłek, który czytelniczka rzeczywiście mogła wykonać, np. zebranie badań
lub próbę zrozumienia zaleceń. Pokaż następny krok. Nie deklaruj bez podstaw,
że najtrudniejszy etap leczenia ma za sobą. Ogólne pochlebstwo nie jest dowodem
zastosowania tej zasady.

### 6. "I couldn't do this either."

Użyj zweryfikowanej osobistej historii autorki, jeśli ją dostarczono i można ją
wykorzystać. Nie dopisuj jej diagnozy, objawów ani dawnych trudności.
Bez takiej historii pomiń zasadę i zapisz powód w audycie. Potwierdzone
doświadczenie zawodowe może budować zaufanie, ale nie dowodzi użycia zasady 6.

### 7. "I'm going to let you in on a little secret..."

Odsłoń użyteczny, mniej oczywisty sposób myślenia związany z produktem,
np. znaczenie celu suplementacji przy ocenie popularnej listy preparatów.
Oprzyj go na źródle lub zweryfikowanym materiale autorki. Nie nazywaj zwykłej
informacji tajemnicą, nie dodawaj teorii spiskowych ani pozornej ekskluzywności.
Samo hasło "decyzje mają sens" nie dowodzi zastosowania tej zasady.

## Przełożenie zasad na stronę

Hero komunikuje potrzebę, rezultat i sposób dojścia do niego. Sekcja problemu
pokazuje rozpoznawalną sytuację. "Dla kogo" pomaga ocenić dopasowanie.
Przy rozdziałach opisz, do czego służy ich wiedza. Efekty mają być osiągalnymi
umiejętnościami, decyzjami lub materiałami do dalszej pracy.

CTA opisuje rzeczywiste działanie, np. zakup dostępnego produktu albo zapis
na listę oczekujących. Powtarzaj je w miejscach, gdzie czytelniczka ma już
wystarczający kontekst. Treść przy cenie i FAQ odpowiada na realne wątpliwości
o pakiet, format, dostarczenie, zakres, przygotowanie i zakup.

W tematach zdrowotnych nie obiecuj zmiany hormonów, masy ciała, cyklu ani
wyleczenia. Nie generuj schematów dawkowania z samego briefu marketingowego.
Twierdzenia medyczne wymagają aktualnych źródeł i weryfikacji. Jeśli nie są
potrzebne do sprzedaży materiału edukacyjnego, opisz użyteczność ebooka.

Opinie cytuj zgodnie z materiałem źródłowym i kontekstem. Recenzja współpracy
z autorką nie jest recenzją ebooka. Liczby, ceny, terminy, doświadczenie i wyniki
muszą mieć źródło. Nie dopisuj kupujących, oszczędności ani gwarancji.

## Audyt przed przekazaniem

Renderowane copy nie zawiera `[[TODO: czego brakuje]]`, `[DO UZUPEŁNIENIA]`
ani `[TWÓJ KONKRET: tekst]`. Lukę landingu zostaw w notatce, poza stroną.
Lukę artykułu zapisz jako `[[TODO: czego brakuje]]` w treści Portable Text.

Uzupełnij tabelę w notatkach roboczych lub raporcie. Dla każdej zasady podaj
krótki dokładny cytat z finalnej strony i nazwę sekcji. Przy braku cytatu
wpisz "brak" i powód. Statusy: użyta, częściowo, pominięta.

| Zasada                             | Cytat i sekcja | Status | Uzasadnienie lub brak danych |
| ---------------------------------- | -------------- | ------ | ---------------------------- |
| 1. Mały krok i istotny wynik       |                |        |                              |
| 2. Duży problem i prosty mechanizm |                |        |                              |
| 3. Bliski pierwszy wynik           |                |        |                              |
| 4. Empatia bez obwiniania          |                |        |                              |
| 5. Uznanie wcześniejszego wysiłku  |                |        |                              |
| 6. Osobista historia autorki       |                |        |                              |
| 7. Użyteczny mniej oczywisty wgląd |                |        |                              |

W audycie pierwszego landingu zasady 1, 4 i 7 były częściowe, 2, 3 i 5 użyte,
a 6 pominięta z braku osobistej historii. To punkt odniesienia dla uczciwego
raportowania. Nie deklaruj 7/7 tylko dlatego, że przeczytano siedem zasad.
