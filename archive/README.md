# Archiwum projektu

## Wonderful — wycofany 07.10.2026

[Pełny dawny design system](wonderful-design-system/README.md) zachowuje
specyfikację, tokeny, katalog, źródła i dowody. Przeniesiony z
`wonderful-design-system/` decyzją użytkownika; nie jest źródłem zasad ani
aktywną zależnością aplikacji. Historyczne propozycje HTML mogą korzystać
z jego zamrożonych tokenów wyłącznie w podglądzie archiwum.

Docelowy system: [3a](../design-system/README.md). Realizujemy 3a;
warianty 01, 1a, 02, 2a i 03 porzucono. Nie usuwać archiwum przy migracji
aktywnych komponentów ani nie nadpisywać go nowymi tokenami.
