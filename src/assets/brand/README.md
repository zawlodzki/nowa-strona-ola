# Logo — aleksandra olesiewicz

Wordmarki tekstowe, bez dodatkowego znaku. Krój: [Gambarino](https://www.fontshare.com/fonts/gambarino)
Regular (Théo Guillard / Indian Type Foundry), z oficjalnego pakietu Fontshare.
Glify są zamienione na obrysy — pliki SVG i PNG nie wymagają zainstalowanej czcionki
i nie zawierają plików fontu.

Kolor: token `ink` (`#171719`). Tło przezroczyste.

| Wariant          | Pliki                                    | Zastosowanie                       |
| ---------------- | ---------------------------------------- | ---------------------------------- |
| Jedna linia      | `logo-wordmark.svg`, `logo-wordmark.png` | Nagłówek, stopka, dokumenty        |
| Słowo pod słowem | `logo-stacked.svg`, `logo-stacked.png`   | Wąskie miejsca, wizytówka, okładka |
| Inicjały `ao`    | `logo-monogram.svg`, `logo-monogram.png` | Favicon, avatar, małe zastosowania |

PNG ma wysoką rozdzielczość (wordmark 3200 px szerokości). Do ciemnego tła zmień
`fill` w SVG na `#ffffff`.

ITF FFL 2.0 zezwala na tworzenie logo i znaków słownych z czcionki. Plików fontu
Gambarino nie hostujemy na stronie — główny krój aplikacji pozostaje Switzer.
